# Story Studio RU/UA — начало работы

Это **рабочая копия Sprint 01**, а не готовый русско-украинский продукт. Исходный код сохранён; добавлены аудит, планирование и журнал.

## Как разместить
1. Создайте папку `Story-Studio-RU-UA` на компьютере.
2. Распакуйте этот ZIP **в корень** папки `Story-Studio-RU-UA`, не создавая дополнительный вложенный уровень.
3. Если уже лежат `MASTER_PROMPT.md` и `story-studio-main.zip`, сохраните исходный ZIP как резервную копию; одинаковый `MASTER_PROMPT.md` можно заменить версией из архива.
4. Следующую сессию начинайте с `project-log/NEXT_SESSION.md`.

**Важно:** исходные корпуса и визуальные материалы не разрешены к публичному/коммерческому распространению до проверки прав.
