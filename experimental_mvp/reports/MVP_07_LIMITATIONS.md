# MVP-07 — реализованные границы и ограничения

Статус экспериментальной поставки: independent review required. **WINDOWS_NOT_RUN**. Production permissions, production storage, CI, main, merge/release и нормативные контракты не затронуты.

## Реализовано

- Чистая transactional модель `timeline.Editor`: create, set/move/resize, duplicate, split, compatible merge, confirmed reference deletion, scene reorder, manual durations, explicit reset/reconciliation, captions, Undo/Redo. ID сохраняются при move/resize; новые ID детерминированно выделяются UUID5 + persisted next_id. Ошибочная операция не меняет проект/историю частично.
- Tk Canvas: сцены, аудио, якоря, титры, монтажный указатель, масштаб/горизонтальная прокрутка, мышь и клавиатура, числовые интервалы, текстовые статусы материалов/конфликтов/прав. Правая граница якоря изменяет длину; тело перемещает. При наложении более поздний нарисованный якорь может закрыть край другого: используйте numeric/keyboard edit или Undo.
- Измерение длительности whole/scene/cache audio через FFprobe без вызова TTS. Численные whole-audio границы — оценка либо явная ручная карта, а не speech alignment. Для отдельных файлов границы следуют измеренным сегментам.
- Сохранение: shape validation, явное draft-confirmation для найденных конфликтов/непригодных материалов, tempfile + replace, сохранность старого файла при отказе; basic editor предупреждает при новом/open/close и при ошибке сохранения не закрывается. Timeline отвергает apply поверх изменённого внешнего проекта.
- FFmpeg: исходный интервал видео, FIT/CROP, image pan/zoom, явные ERROR/HOLD_LAST_FRAME/LOOP, смешанные форматы, cumulative frame budget, duration-check до публикации final.mp4, copied-input hashes и provenance. Скорость AI-видео не изменяется.

## Формат и совместимость

Старые опубликованные JSON без timeline-полей остаются пригодны для прежнего load/save/build. Существующие тесты не изменены. Новые операции opt-in добавляют:

| Поле | Смысл |
|---|---|
| `timeline.version = 1` | Только экспериментальный формат; не нормативный PG/G3.2.1 contract |
| `timeline.next_id` | Счётчик детерминированного выделения новых anchor_id |
| `timeline.scene_durations_ms` | Необязательная map scene_id → ручная длина. Порядок сцен задаёт cumulative start. При общей записи остаток распределяется между сценами без ручной длины. Все ручные длины вместе должны покрывать измеренную запись |
| `source_start_ms`, `source_end_ms` | Исходный видеоинтервал, end exclusive; отсутствующий end означает фактически измеренный конец файла |
| `source_duration_ms` | Необязательная описательная метаинформация; фактический файл всё равно перепроверяется FFprobe |
| `short_clip_policy` | Новая timeline по умолчанию ERROR; HOLD_LAST_FRAME или LOOP — только явный выбор |
| `fit_mode` | FIT с полями либо центральный CROP; произвольное интерактивное кадрирование не реализовано |
| `allow_outside_scene` | Явное разрешение держать конфликтный интервал в черновике; не разрешение экспортировать его |
| `cue.timing_kind` | ESTIMATED_CAPTION_TIMING / MANUAL_CAPTION_TIMING; старые overrides считаются ручными, отсутствующие overrides оценочными |

Audio Timing Map содержит MEASURED_AUDIO_DURATION, ESTIMATED_SCENE_BOUNDARY, MANUAL_SCENE_BOUNDARY и виды тайминга титров. При неподготовленной озвучке UI может показать плановую оценку **UNKNOWN_NOT_MEASURED**. Она не становится измеренной от редактирования ручной длины. При негодной manual map показывается явно обозначенная оценка по измеренному аудио; сам проект не исправляется автоматически.

Legacy проекты сохраняют опубликованное implicit hold-last-frame поведение с предупреждением в FFmpeg log. После opt-in timeline v1 недостаток видео требует явного решения. Это намеренная безопасная граница совместимости, не скрытая смена скорости. Выбор trim означает явное сокращение timeline length / выбранного интервала с последующим исправлением покрытия.

## Практические ограничения

- **Это prerender editor, не встроенный синхронный AV-плеер.** OS player не сообщает позицию обратно. Указатель Canvas — позиция монтажа. Preview с позиции создаёт остаток **текущей сцены**, не непрерывное воспроизведение оставшегося проекта. Whole-project preview — отдельная команда.
- Preview рендерит глубокую копию, результаты находятся в отдельных temporary preview folders; исходный JSON/материалы не меняются. При изменении редактора во время render готовый preview помечается устаревшим. Временные папки не удаляются автоматически: пользователь может удалить их после просмотра.
- Cancellation cooperative: проверка между FFmpeg командами/якорями и перед выдачей результата. Уже выполняющаяся команда завершается или достигает timeout (обычно 300 s); немедленного OS process termination нет. Отменённый результат не открывается как успешный preview.
- Undo/Redo ограничены 100 timeline-транзакциями текущей сессии. Это не глобальная история старых вкладок и не история между запусками. Native Text widgets сохраняют собственный undo текста. Удаление ссылок никогда физически не удаляет файлы.
- Import материала используется из существующей «Раскадровки»: примените timeline к основному проекту, загрузите раскадровку, импортируйте/примените и заново загрузите timeline. Есть защита stale apply; автоматического merge двух расходящихся editing snapshots нет.
- При перестановке сцен whole recording физически не переставляется. UI предупреждает; нужна проверка смысла/границ. Отдельные scene files/cache следуют за ID. Изменение длины независимого аудиофайла требует явной обработки самого аудио: незаметного time-stretch/pad нет.
- Ручные границы, якоря и титры могут временно конфликтовать. Сохранение конфликтного черновика требует согласия; экспорт требует исправления. Добавляя сцену к полностью вручную размеченной общей записи, явно переразметьте границы/измените аудио; «Оценить границы» не удаляет якоря/титры и доступна с Undo.
- Split обычного video использует один исходный файл и соседние source in/out; repeated/held clips не делятся неявно. Сначала выберите конечные интервалы/сократите длину либо оставьте отдельно управляемые якоря. Merge разрешён только для совместимых metadata/material/provenance и соседних video source intervals.
- Миллисекундные интервалы монтажа реализуются выходными кадрами. Cumulative rounding не накапливает независимое округление каждого якоря; интервал короче одного кадра не экспортируется. После сборки допустимая ошибка `max(0.1 s, 2 / FPS)` относительно измеренного аудио; превышение блокирует final publication.
- LOOP кэширует кадры выбранного исходного интервала в FFmpeg; длинные/тяжёлые источники могут требовать значительных ресурсов. Рекомендованы короткие 5–10 s клипы. Нет GPU-зависимости, waveform, ASR/forced alignment, произвольного speed change, фоновой media API генерации или production rights gate.
- Hash checks фиксируют изменения и скопированные входы, но не закрывают TOCTOU, hostile concurrent writes, Windows reparse points, malicious codecs или подделку license metadata. Это trusted-user local experimental workspace, не защищённый executor/storage.
- Нет Windows 10/11 qualification, OS-player playback, human listening/synchronization или научной/редакционной приёмки демонстраций. Размеры/шрифты/HiDPI и реальные shell/file-dialog особенности Windows требуют отдельной проверки.
