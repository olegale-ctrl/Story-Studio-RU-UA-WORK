# MVP-08A — Known limitations and open qualification

- Windows10/11/NTFS/junctions/reparse/ACL/antivirus/file-locking/HiDPI/Tk native dialogs and CPU performance are **WINDOWS_NOT_RUN**. The conditional junction test is skipped, not PASS. Linux symlink tests do not close it.
- This library is trusted-user experimental storage. No adversarial immutability, protected filesystem handles across every operation, ACL qualification, OS decoder sandbox, authenticated rights documents, signed audit store or production permission exists. TOCTOU/hardlink/parent replacement/privileged mutation risks remain.
- Integrity/lifecycle in catalog reads is the last recorded observation, not a file watcher. Resolve/verify/recovery recheck actual bytes before use; external changes can leave cached status stale until checked.
- DB transaction and filesystem publication aren't one atomic resource. Pending imports abort on recovery; complete orphan objects are retained and can be reused only by explicit verified re-import. Pending metadata may require re-entry after an aborted import; only committed records and source bytes are covered by the tested preservation model. No physical garbage collection/deletion, no quota manager, disk reservation or power-loss durability claim. This avoids deleting shared user content from incomplete reference knowledge.
- `links` is attachment history/observed association labels, including detached observations. It is not automatically synchronized with every saved JSON, Timeline Undo/duplicate/delete, renamed topic or moved project. Project JSON controls actual bindings. An unapplied link observation is possible after cancelled/stale application; no automatic repair rewrites scenes. Search project/anchor returns historical observations as documented.
- One local library root per GUI tab, no multi-user collaboration, network shares, automatic portable relocation, external watchers or remote storage. Stable offset pages assume fixed catalog snapshot; concurrent inserts may change page membership. Search is exact/UTCISO range, no semantic AI search.
- Rights/revision checks occur before resolution/use; revocation after the final check cannot atomically cancel an already-running native render. In-flight revocation enforcement needs a separately qualified executor/gate.
- Rights gate checks local metadata, not legal truth. UNKNOWN never clears; strings do not prove licences/consent. CLEARED_FOR_EXPERIMENT is not production clearance. Expiration NOT_APPLICABLE is an explicit reviewer statement; territory/attribution/applicable usage still need human verification. No live provider or model identity verified.
- Default import limits128MiB,120s,onevisualstream,≤8streams,8192dimension/32Mpixels,20s command timeout. Larger/longer legitimate assets are rejected instead of partially accepted. SQLite writer lock can wait90s; imports serialize through validation. Parser native memory and CPU limits are not OS sandbox guarantees.
- Import worker is not instantly cancellable; closing panel may let its bounded local operation finish/catalog an asset. It cannot apply a result to a closed or changed project. No remote operation exists. Recovery/verify must run explicitly through UI/API; on restart no silent reconstruction or assumed success.
- Thumbnail is first-frame static image, max512, not a player, quality judgement or exact colour management. Fixed tool/input/params determinism tested; FFmpeg version changes may alter output. Explicitly registered previews use DERIVED provenance; no automatic lifecycle promotion to approved.
- Existing17 VideoAnchor fields retained; binding is optional experimental metadata. Latest metadata revision never silently replaces a pinned scene. Any metadata change requires explicit reattachment; this is conservative even for a harmless tag change. Retired assets stay retired, old metadata retained. No production migration/contract change.
- GUI metadata editing uses a JSON dialog, simple table and fixed pages; no rich media browser, waveform, batch rights review or advanced filtering. Apply Timeline and save project explicitly. Long operations run off Tk thread; heavy work is not parallelized for throughput.
- Synthetic local fixtures prove mechanics/technical decode only. No external-generation quality, human listening/synchronization, scientific validity, real rights review or commercial export acceptance performed. No MVP-08B implementation, production rollout or release authorization.
