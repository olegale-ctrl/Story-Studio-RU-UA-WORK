Для каждого D-ID зафиксировать выбранный вариант/поправки, уполномоченное лицо, дату, scope, исключения, срок и условия пересмотра. Отсутствие ответа не является одобрением. Рекомендации не выбираются автоматически.

Перед будущим live pilot отдельно определить тему и права на inputs, регион и retention, reviewer качества, предельную стоимость и порядок разбора неизвестного списания. Здесь нет разрешения на регистрацию, покупки или API-запросы. Main, CI, merge, release, G3.2.1, production storage и production permissions остаются STOP.

Открытые блокировки: нет квалифицированного аккаунта/ключа; API execution NOT_RUN; неполные legal/region entitlements; конфликт коммерческих clauses PixVerse; конфликт free/API scope Renderforest; FusionBrain docs недоступны; Kling direct specs частичны; rate/retry/refund/cancel не квалифицированы; Windows NOT_RUN; регулярный free API supply не доказан; Asset Library и защищённый executor отсутствуют; художественная и научная приёмка не квалифицированы.
