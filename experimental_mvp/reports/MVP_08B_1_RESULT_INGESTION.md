# Result ingestion and decoded-media evidence contract

EXISTING I03/I04/I08 supply local import/hash/probe/decode checks. No network downloader exists. All following ingestion behavior is PROPOSED, NOT_IMPLEMENTED. Live transfers remain STOP even when a result URL is known.

## Trusted association before bytes

Validate artifact→job→attempt→provider_job_id→requested/resolved model/version/region association against durable acknowledgement and qualified receipt. Wrong job/model/region or unsigned/unverifiable association → NEEDS_RECONCILIATION or FAILED for a proven non-associated artifact; never relabel a mismatched file with the expected model. Provider download hash, if available, is a claimed origin receipt; local SHA alone proves only byte identity. Multiple outputs have independent artifact IDs/hashes/validation/rights; partial completion is explicit. Duplicate callbacks cannot trigger duplicate imports or attachment.

## Proposed transport policy (future only)

HTTPS only, exact qualified origin/port allowlist for provider/CDN, no userinfo/fragments or URLs from untrusted prompt. Deny loopback,private,link-local,multicast,unspecified,metadata endpoints,IPv4-mapped/privateIPv6 and ambiguous IP representations. Resolve+validate every address; connect to validated address and check peer with TLS hostname validation; revalidate each redirect and new connection to resist rebinding. Redirect policy default0; a qualified chain may allow≤3 redirects with fresh host/DNS/peer checks and no credential forwarding across origin. Never disableTLS, derive host allowlist from returnedURL or use a browser session token. A pure URL string validator cannot close OS/DNS/proxy TOCTOU; future executor/network policy qualification OD07 required.

Default proposal: connect5s, idle10s,total60s, stream byte ceiling≤134217728, Content-Length if supplied must be finite nonnegative ≤ceiling and agree with transferred decoded HTTP body; missing length still bounded by streaming counter, not assumed zero. Reject unsupported Content-Encoding or count expanded bytes separately. No unlimited chunked body, decompression bomb, redirect loop, auth-header leak or proxy bypass. Values are proposals needing resource qualification, not measured provider SLA. Offline simulator uses fixture IDs and managed local byte streams only; any URL/nonlocalpath in its fixture is an illegal event, zero sockets expected.

Write to per-job/attempt/artifact private staging filename, not server filename; no traversal/symlink/junction following, no executable file handling or autoplay. Stream SHA256 and byte count,flush/fsync,verify declared/actual hash,freeze artifact receipt/validator/expiry. Resume only if same qualified immutable artifact identity+ETag/version/range semantics and local partial hash checkpoint agree; otherwise restart download of the same known result into new staging, **not new generation**. Staging cleanup only managed namespace; corrupted/missing uncertain evidence is not auto-reconstructed. Original bytes retained; normalized derivatives separately hashed/linked and never replace the original hash silently.

## Validation manifest VAL-v1

Required: job/attempt/artifact and source receipt; original SHA/byte size; requested+actual container/codec/native resolution/ratio/duration; tool executable/version/arguments/policy digests; validated stream inventory; decoded-frame evidence DFE-v1; audio evidence; limits/tolerance; exit codes/stderr classification; validation status and failure reason; paths represented by controlled refs, not trusted external locations. Unknown required measurement => INCOMPLETE, cannot mark validated/complete. Technical validity never proves artistic relevance, speech synchronization, scientific truth or rights.

Proposed default accepted output MP4/H.264,onevisualstream,expected pixel bounds and rational frame timestamps; AAC optional audio only if request declares permitted audio. Disallow unexpected attachment/data/subtitle/extra audio streams unless explicitly covered. Audio channels/sample rate/duration checked against qualified profile; no synthesized voice/likeness clearance inferred from codec. Exact policy is OPEN OD04, default reject unsupported combinations rather than silent transcode/upsample. Requested1080p isn't satisfied by blindly trusting an upscaled label; native/derived resolution recorded separately.

Duration proposed tolerance max(100ms,2 video-frame periods), measured from decoded presentation timeline and relevant container/audio evidence; rational timestamps for VFR, not frame_count/FPS shortcut. If timing evidence contradictory/unknown, hold. Truncated video with successful header probe still fails full decode. Resource-killed or bounded-partial decode is INCOMPLETE and cannot assert whole-file frame count/quality. Entire video decode must complete within qualified limits for attach; otherwise explicit separate qualification, not guessed counts.

## P1-01 — DFE-v1

Base technical.frame_count parses FFprobe nb_frames and can beUNKNOWN. Full FFmpeg exit0 alone doesn't supply decoded frame count. Proposed manifest stores separately container_reported_nb_frames,probe_nb_read_frames if using actual frame-reading,independent_decoder_frame_count,decoded_timestamp_span,frames_discarded/duplicated,decode_complete,tool/version/policy,exit_codes. Count actual successfully decoded source frames without output rate conversion/loop/hold; don't use Timeline render frame budget or nb_frames as decoded count. Any independent-count method must be qualified for VFR/B-frames/corrupt-tail/duplicates and tool parsing. If nb_frames disagrees with verified decoded count, preserve both and mismatch flag; fail closed for attachment pending OD04 policy, never overwrite or “correct” the existing AssetRecord technical.frame_count as though already implemented. Base Library lacks this manifest field; store sidecar JobEvidence and pin its SHA plus asset SHA/revision; future Library extension needs OD04, not a silent current change.
