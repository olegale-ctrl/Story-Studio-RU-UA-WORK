Local MP3/WAV mode requires no pip packages, network, accounts or edge-tts. Render uses CPU libx264. For optional remote LLM keys install `keyring` separately, then use **Ключ → Windows vault**. Only the Windows keyring backend is accepted; plaintext/file backends are refused. No keys, passwords, Google credentials or session cookies are saved to project JSON. The Windows vault path itself is NOT_RUN here. A loopback model without a key works without keyring. The LLM endpoint is an OpenAI-compatible base such as `http://localhost:11434/v1`; append neither `/chat/completions` nor secrets. External endpoints require HTTPS. Redirects are refused. Each LLM request asks consent to send the topic and possible cost.

1. **Демо RU / Демо UA** opens a complete portable manual/offline project, eight scenes, original local diagrams and included local eSpeak NG MP3. Save to the managed project workspace. Check/review the script and explicitly confirm **локальная сборка** before preview/export. This checkbox conveys no production permissions.
2. For a new topic use **Новый**, choose ru/uk, enter the topic. **Сценарист** supports a manual JSON draft/import or a compatible LLM. Generation produces an UNVERIFIED draft. Edit it and apply explicitly to an empty project. Existing scenes are deliberately preserved: edit them in **Сцены** rather than overwriting their anchors/assets with a fresh draft. Existing Story Intelligence JSON analysis remains available through its established Editor Preview input contract; an arbitrary LLM draft is not a verified Evaluation or Decision Projection.
3. **Раскадровка → Загрузить текущие сцены** creates an editing snapshot. Select a scene and **Предложить якоря** using measured/planned scene duration (5 / 6–8 / 10 seconds are guidance, not provider capabilities). Existing anchors are never silently replaced. Select an anchor, use **Изменить якорь…** for a field form or the advanced JSON, then explicitly apply/save the storyboard. Reload it after changing scene composition. Reorder changes temporal positions and retains IDs/assets. Split retains source paths and offsets. Script edits retain assets but may require manually adjusting time coverage.
4. Modes: AI_VIDEO, LOCAL_VIDEO, STOCK_VIDEO import video; AI_IMAGE/MAP/INFOGRAPHIC import corresponding still material; IMAGE_PAN_ZOOM animates a still; TEXT_ANIMATION locally animates its description/excerpt (local TTF required); PLACEHOLDER is a neutral color only. Missing AI media can use explicitly chosen `fallback_mode=PLACEHOLDER`. There is no automatic stock search, map engine or infographic authoring service. Missing or corrupted imported files produce errors, never silent substitution.
5. **AI-сервисы** opens official sites in the system browser. Check actual country eligibility, model, credits and rights there. Use Google only if the official site offers it. The app never collects a Google password, bypasses CAPTCHA/MFA, or creates accounts. You can decline login and continue offline. **Проверить состояние** displays configuration/self-reported state; it does not attest an authenticated browser/API session.
6. The account editor accepts only the shown non-secret fields. Record balance/cost in the same unit, source, supported durations, timezone-aware `confirmed_at`, `valid_until` and optional `reset_at`, for example `2026-11-18T12:00:00+02:00`. UNKNOWN or expired balance produces WAITING_FOR_QUOTA, unsupported/unknown duration requires review. A reset invalidates the observation; it never silently refills the balance. READY is an estimate, not a reservation or charge. All media generation remains manual. Open the site, copy prompt, generate there, download, then import the result. The app never submits media jobs or spends credits.
7. Imported files are copied into a content-addressed local media workspace. Save the project; portable transfer requires those referenced assets too. Included demo `./` media references resolve relative to their JSON. Short videos freeze the last frame to fill an anchor; long clips are trimmed; imported audio is not time-stretched. FPS/resolution are normalized. Inspect this editorially, especially scene boundaries estimated from whole narration.
8. **Проверить проект**, subtitle editor, scene preview and movie preview precede **Собрать MP4**. Incomplete exports never appear as completed history. Cancellation is checked between phases/anchors; an active FFmpeg command completes or times out first. Resume reuses prepared audio; video rendering restarts. The result folder contains MP4, captions, timing, input snapshot, logs and experimental execution evidence.
