**SP-INTEGRATION-01 · PROPOSAL · 2026-11-19 · no production authority.**

|Class|Required evidence / policy|Current behavior|
|---|---|---|
|none|Exact requested inputs and execution scope|Still blocked on Dispatcher, authority and storage|

First Video's generated background is not used as an implicit fallback: D/final diagnostics require explicit images. Existing D1 synthetic palette/audio remain scoped to its own registered test, not production media. Synthetic completion is not permission to substitute generated materials into an actual film.

A future qualified degraded policy must state loss, permissible downstream uses and human review; a boolean `allow_degraded` alone is insufficient. Equivalent requires actual evidence, not a filename match. Draft still needs execution authorization where applicable and cannot bypass gates/rights. No ALLOW_DRAFT file or skip-gates option is supported. Changes in provider/model/region/cost/data-transfer scope require the applicable renewed owner confirmation under D01-D08; quota exhaustion never automatically switches to paid generation.
