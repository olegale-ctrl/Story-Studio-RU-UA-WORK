`INCLUDE` означает кандидат на отдельное будущее owner-approved задание, а не перенос этим аудитом. Минимальный D1 комплект: **4 INCLUDE**. **193 DEFER** — отдельные треки/исторические материалы, **4 EXCLUDE** — не копировать source snapshot README, ignore и project logs; точечные новые правки при необходимости обсуждать отдельно. Для Markdown это найденные ссылки/цитаты, не runtime imports и не доказательство авторизации. Нет ссылки не означает отсутствие нормативной зависимости; ключевые ручные зависимости описаны в матрице. `test_*` — статический счётчик объявлений, не число реально выполненных тестов.
