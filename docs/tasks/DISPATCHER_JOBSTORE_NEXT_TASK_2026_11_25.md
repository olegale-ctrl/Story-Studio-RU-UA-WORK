## DQ-01 — отдельное предварительное условие для native

Повтор 396 pure тестов не заменяет независимую приёмку Stage A. Для native задачи нужны точный разрешённый root, подтверждённый профиль OS/filesystem/SQLite, ограничения записи/места/времени и отдельные условия fault injection. Облачный preflight success не определяет эти параметры. При отсутствии одного из них NATIVE_BLOCKED_PRE_WRITE_GATE сохраняется.
