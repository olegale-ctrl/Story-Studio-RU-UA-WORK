## 2. Blocking local defect — SI-F1: captured Brief/Creative refs may be null

**Contract basis:** R1 §4.3 `BriefReviewState` is the projection of exact current refs; R1 §5.1–§5.3 `ReviewPacket` has mandatory `brief_ref:SIRef` and captures the corresponding `review_state_at_capture` for a packet produced **after** the Brief; original ProductionBrief schema requires `creative_ref:SIRef`. R1b-P03 keeps this projection in `review_state_at_capture` and does not relax its semantics.

**Observed implementation:** `records_v1.py` defines the general projection value with nullable `creative_ref` and `brief_ref`, which is correct for a standalone pre-Brief projection. In the Packet-specific `_packet` checker, however, the condition is only:

```python
if review['brief_ref'] is not None and review['brief_ref'] != p['brief_ref']:
    _fail('PROVENANCE_MISMATCH', base + '.review_state_at_capture.brief_ref', 'Captured Brief differs')
```

Thus **null** bypasses the equality check. The same Packet-specific checker does not require `review_state_at_capture.creative_ref` non-null even though a persisted Packet necessarily refers to a Brief with a required CreativeAlternative. It can accept a structurally self-contradictory captured projection. Existing positive fixtures use both refs non-null and do not exercise these null cases.

**Minimal negative reproducer to execute in the fix task** (not independently executed in this static review):


Neither change affects the Packet source-snapshot digest or capture context hash, so the existing digest checks do not detect the contradiction. The correct Packet-specific local invariant is **captured brief_ref non-null and exactly equal to Packet.brief_ref; captured creative_ref non-null**. Exact CreativeAlternative-to-Brief ref matching requires resolving the referenced Brief and is **deferred**; no fake proof of that external equality.
