The suggested B_unique/B_read split refines the **unapproved** C proposal to expose physical work; it does not silently amend an approved counting rule. Different identities with identical bytes charge B_unique separately unless a separately reviewed equivalence model is chosen. Repeated exact edges spend E_occ even with cached target; logical parsing once requires verified same identity/bytes and cache accounting, not simply a user-provided digest string. All actual reads spend B_read. Conflicting identity must not be deduplicated away before conflict checks; failed attempts spend work already performed. No unlimited fresh budget per dependency, locale, phase, failed retry or cache reset within one invocation.

Candidate accepted workload is the **intersection** of all selected caps and schema/semantic constraints, not simultaneous attainment of every maximum. Numeric model needs L_Bread≥L_Bunique for first-read compatibility if both selected, but re-read headroom is an explicit policy choice, not assumed. L_D can conservatively be constrained by available parsed wire accounting; it need not allow all wire bytes. Inputs exceeding a counter deny at the applicable already-approved stage; missing profile is not an unbounded default and cannot produce consistency/operation permission. Exact missing-profile public mapping is a future decision, not a new PG code here.

## 2. Deterministic arithmetic and amplification

Under proposed units for nonempty arrays of n scalars: N=n+1,T=2n+1. At n10000, N10001,T20001; a local array guard does not bound aggregate. Root array containing K arrays of n scalars has N=1+K(n+1),T=K(2n+2)+1 for K,n≥1. One object with m scalar members, m≥1: N=1+2m,T=4m+1. Empty containers have2 punctuation tokens; do not apply the nonempty formula to them.

These are read-only arithmetic identities, not new fixture IDs, selected caps or parser tests. Token count does not bound long string/comparison work; common-prefix keys add sorting cost. C's loose T≤3N is a sanity inequality under these units, not a replacement for measured CPU/RAM or all malformed-prefix accounting. UTF8/key/string decoded bytes are measured after unescaping; raw escape expansion remains in W. Aggregate byte count must include binaries never parsed as JSON. Render output inspection budgets are separate future policies; no input-budget loophole licenses unlimited output.

## 6. Reporting is not proof of no effects

F-D03 can fix exact result bytes/verdict/code/private separation and absence of grant fields. It cannot establish zero process spawns, file/network/store writes or no privilege/permission changes. Those require F-D09 and qualified independent observation. A function's returned object or self-reported zero-call counter is not a whole-process/OS effect boundary. Keep whole-PG CONSISTENT distinct from canonical/field-shape success; fixed safe messages and STRUCTURALLY_VALID descriptions do not grant render authority. P1-DIAG-01 does not approve a new report record's field registry.
