Each row maps one approved rule to a pinned existing vector or oracle. New CM IDs identify **documentation rows only**, not newly created vectors/tests. All technical sources are from exact accepted C base `86ae74058c2a90b563855eac15f46ff8b3be28e4`.

Universe87 vector IDs/58 oracle IDs checked; citations resolve. Full literal bytes/recipes and expected-hash fields remain in those immutable source records.
- COVERED_BY_VECTOR = an existing literal/recipe covers the named isolated layer, **not a runtime PASS**. PARTIAL = oracle/partial probe or external unresolved dependency. MISSING = MISSING_VECTOR, future specification only; no fabricated bytes/digest. PURE/CONDITIONAL/FUTURE describe test class, not grant.
- DOC_INSPECTION = read and compare rules/expected text. HASH_RECHECK = actual SHA-256 arithmetic on published expected canonical bytes, not production serialization or semantic validation. NOT_RUN = future executable case was not run. All behavioral/PG semantics, native/provider/integration/render tests remain NOT_RUN even on HASH_RECHECK rows.
- Boundary vectors formerly conditional on P1 values now match owner-selected caps; their other schema/semantic/resource assumptions remain conditional. A positive value probe is not a PG root or CONSISTENT_NO_AUTHORITY verdict. Historical source approvals/comments are interpreted via the new owner record only for eight P1 choices.
