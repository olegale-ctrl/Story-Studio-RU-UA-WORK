# Работа со Story Studio RU/UA в Codex

Это краткое руководство по подключению **существующего** приватного репозитория. Оно не запускает новую разработку и не изменяет установленный Windows-проект.

## Источник истины
Репозиторий: https://github.com/olegale-ctrl/Story-Studio-RU-UA-WORK

Ветка `main` — рабочая основа Sprint 26. Sprint 25.1 остаётся резервной локальной версией. Экспериментальный CPU Lip Sync — отдельный, ещё не слитый PR #5.

## Как открыть в Codex
1. Перейти на https://chatgpt.com/codex и при необходимости подключить свою учётную запись GitHub.
2. Выбрать существующий **приватный** репозиторий `olegale-ctrl/Story-Studio-RU-UA-WORK`.
3. Для первой задачи использовать `main` **после принятия документационного PR**, содержащего `AGENTS.md`, или указать ветку этого PR, если интерфейс позволяет.
4. Первый запрос: «Прочитай `AGENTS.md` и `project-log/CODEX_HANDOFF.md`. Выполни только read-only аудит оригинального Story Studio и нашей базы Sprint 26, перепроверь `docs/UPSTREAM_DEEP_AUDIT_2026-11-04.md`; представь подтверждённые ошибки, ограничения, приоритеты и проектный план. Не меняй код и не устанавливай зависимости без моего разрешения».
5. Не выбирать автоматический merge до проверки предложений, особенно для лицензий, моделей и видеозависимостей.

Если Codex запускается локально, можно открыть **существующую** папку Sprint 26. Не скачивать новый репозиторий в отдельную папку спринта, не удалять `.venv`, `.tools`, голосовые модели и выходные MP4.

## Ключевые документы
- `AGENTS.md` — короткие инструкции для Codex.
- `MASTER_PROMPT.md` — продуктовые и юридические требования, действующая политика релизов.
- `project-log/CODEX_HANDOFF.md` — актуальная передача контекста.
- `docs/UPSTREAM_DEEP_AUDIT_2026-11-04.md` — результаты и неподтверждённые гипотезы о китайском оригинале.
- `project-log/WORKLOG.md`, `ROADMAP_STATUS.md`, `NEXT_SESSION.md`, `DECISIONS.md`, `LICENSE_REVIEW_LOG.md` — хронология, решения и открытые ворота качества.

## Как вести дальнейшие изменения
Только после отдельного согласования: ветка задачи -> ограниченный diff -> тесты с доказательствами -> PR -> просмотр -> слияние. Для Windows-пользователя поставляются компактные ZIP-накладки поверх одной рабочей папки, но *только если они реально собраны и проверены*. Изменение документации не является Sprint 27 и не требует установки.
