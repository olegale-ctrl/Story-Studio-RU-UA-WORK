## Метод и уровень доказательств

Пять исследовательских агентов проверяли данные/Analytics, A/B-статистику, ML/утечки, права/Windows и оригинал/Narrative. Отдельный критический агент независимо проверял ключевые формулы и пути в исходниках; во второй волне исследованы дополнительные альтернативы.

- **FACT / SOURCE-CONFIRMED:** прямо видно в закреплённом исходнике или документе.
- **CALCULATED:** собственный безопасный расчёт stdlib по опубликованным числам/формулам.
- **INFERENCE / RISK:** обоснованная интерпретация, влияние или эксплуатация не воспроизведены.
- **UNTESTED / UNVERIFIED:** нужны runtime, доступ к первоисточнику, права, данные или отдельная проверка.

Читались исходники, Git tree, JSON/notebook metadata, CSV небольшого C01 и первичные авторские PDF. Выполнялись собственные JSON/AST-подсчёты, арифметические контрпримеры и безопасный разбор pickle opcodes без десериализации. Наличие чужого теста или сохранённого notebook output не засчитывалось как выполненный нами тест.

Внешние программы, модели, установщики, обучение, paid API и live YouTube Analytics не запускались. Полные project tests повторно не запускались. Для некоторых официальных страниц Google, ACM, Dataverse и Hugging Face сеть возвращала 403; политика не обходилась и не менялась.

Методическое исключение: при инвентаризации vRetention ошибочно был получен CSV около 90,4 МБ как Git blob до проверки размера. Файл и та временная копия удалены без анализа; повторная загрузка датасета не проводилась. Полный состав или статистическая достоверность этого датасета не подтверждены.

## Решения и границы

`REIMPLEMENT IDEA` означает самостоятельную реализацию общей идеи с оригинальными материалами. `EXPERIMENT` — отдельную проверку после разрешения. `BLOCKED` — конкретный нерешённый gate. `REJECT` — отказ от указанного применения, не утверждение о полной бесполезности проекта.

Статус `ADOPT` не присвоен ни одному внешнему компоненту. Код, данные, веса, API и output rights оцениваются отдельно; этот отчёт не является юридическим заключением. Исходные C03/C06/C11 не подменяются найденными альтернативами.

Рабочий код, зависимости, lockfiles, модели, медиа, CI и gitlink оригинала данным набором документов не изменяются. Архитектура остаётся предложением; PR предназначен для review без merge и без release.
