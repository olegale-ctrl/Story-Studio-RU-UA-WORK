# Sprint 02 — статический аудит зависимостей (предварительно)
Дата: 2026-10-30. Анализ локального исходного архива; **без проверки лицензий через интернет** и без загрузки моделей.

## Подтверждено непосредственно кодом `scripts/setup_dependencies.py`
- `pyJianYingDraft==0.3.1` — модуль `draft`.
- `Pillow>=10,<13` — модуль `draft`, диапазон, не фиксированная версия.
- `numpy>=1.24,<3` — модуль `draft`, диапазон.
- `websockets==15.0.1` — модуль `tts`.
- `@marswave/coli@0.0.20` — CLI для ASR.
- В режиме `draft` проверяется наличие `pymediainfo` и системного `libmediainfo`, но точная версия/цепочка установки требует отдельного анализа.
- `ffmpeg` и `ffprobe` используются для аудио/видео.
- Есть загрузка удалённого skill через GitHub; источник, ревизия и лицензии каждого такого пакета должны проверяться отдельно.

## Лицензионный статус
Все перечисленные сторонние компоненты: `REVIEW REQUIRED` до проверки точной версии, полного дерева транзитивных зависимостей, текстов лицензий, условий распространения и уведомлений. Известная лицензия пакета из памяти или общего описания **не считается проверкой**.

## Риски
1. Отсутствует единый lockfile для всех платформ и режимов.
2. Диапазоны Pillow/numpy создают неповторяемые сборки.
3. Динамически скачиваемые инструменты и модели не покрываются простым Python SBOM.
4. Исходный китайский корпус и референсы остаются `BLOCKED` для публичной/коммерческой поставки до установления происхождения.
5. Не проведена проверка прав на названия, брендинг и сторонние голоса.

## Что проверять далее
- `scripts/bootstrap_environment.py` и `scripts/setup_dependencies.py`: все URL и команды установки;
- фактические метаданные релизов/лицензий зависимостей;
- транзитивные пакеты в чистой тестовой среде;
- SBOM для конкретной собранной версии;
- условия поставщиков TTS/ASR/LLM и веса моделей.
